# Demo React App

Petite application de démonstration en React + TypeScript, construite avec Vite : une liste de tâches simple (ajout, complétion, suppression, filtres).

## Démarrer

```bash
npm install
npm run dev
```

## Scripts disponibles

- `npm run dev` — démarre le serveur de développement
- `npm run build` — compile les types et build l'app pour la production
- `npm run lint` — vérifie le code avec Oxlint
- `npm run preview` — prévisualise le build de production
